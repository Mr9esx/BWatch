# B 站与小红书内容归档：可行性与技术设计

日期：2026-10-21

## 目标

在现有单用户内容归档服务中支持 B 站与小红书博主的视频和图文存档，并把平台差异收敛在可替换的适配器中。调度、去重、任务状态、本地文件管理和前端内容库由共享核心提供。

本次只支持 B 站和小红书。YouTube 不属于本次产品范围；当前代码中的 YouTube 分支和面向 YouTube 的界面提示应在实现中清理，避免继续作为可添加平台出现。

## 仓库现状

- 后端是 Go 单进程服务，状态存入 JSON；扫描调度、队列、内容类型和存档任务均在 `internal/app`。
- 前端是 React/TypeScript；订阅、任务、内容库和设置页面已有 B 站中心语义。
- B 站投稿列表和动态列表由本地实现扫描；视频由 yt-dlp 下载；动态中的图片通过 Go HTTP 客户端下载并打包。B 站扫码登录已实现，当前 Cookie 路径仍是全局设置。
- `Creator` 同时存储 `WatchVideos`、`WatchDynamics`、`Seen`、`SeenDynamics`；`Task.Kind` 使用 `video` 与 B 站专属的 `dynamic`。历史拉取仅连接 B 站。
- yt-dlp 用于媒体下载，不是系统的统一平台发现层。小红书要列出博主笔记、区分图文和视频、读取图文全部图片，需要额外的发现与笔记详情能力。

## 可行性结论

### 小红书登录

小红书应用内扫码登录可行，但当前未发现面向个人博主笔记归档的官方开放 API。官方开放平台文档定位于电商应用能力；小红书创作服务平台提供网页登录。GitHub 上的非官方客户端已实现小红书二维码创建和状态轮询，说明网页会话登录可落地，但这些协议并非稳定公开 API，必须视为易变的适配器实现。[小红书开放平台开发说明](https://open.xiaohongshu.com/document/developer/file/33) [非官方客户端中的二维码登录实现](https://github.com/ReaJason/xhs/blob/master/xhs/core.py)

建议由 Go 后端向前端提供扫码会话：申请二维码、返回二维码内容和有效期、轮询登录状态、成功后将 Cookie/会话保存在本机数据目录。平台登录状态和凭据分开存储。过期时报告需要重新登录，不退回匿名扫描。

### 笔记发现与 yt-dlp 边界

yt-dlp 当前包含 B 站及小红书单条笔记提取器。小红书提取器的 URL 匹配仅针对 `/explore/<id>` 和 `/discovery/item/<id>`，提取视频流和笔记图片 URL；这些图片以 `thumbnails` 字段返回，而非作为图文帖的媒体文件列表。当前没有博主主页笔记列表提取器。因此 yt-dlp 不足以承担小红书订阅发现，也不能直接作为图文原图存档方案。[yt-dlp 支持站点列表](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) [小红书提取器源码](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/xiaohongshu.py)

近期 yt-dlp 问题记录过小红书视频笔记无法提取元数据或视频格式的情况，说明即使单条视频提取器存在，成功率仍受平台网页和风控变化影响。[无法提取视频格式的问题](https://github.com/yt-dlp/yt-dlp/issues/12719) [提取器故障报告](https://github.com/yt-dlp/yt-dlp/issues/15467)

处理分工：

- 视频媒体统一通过 yt-dlp 下载，平台适配器负责给出规范化的笔记 URL、Cookie 文件和必要的请求选项。yt-dlp 失败应保留任务错误和重试能力。
- 图文原图由平台适配器发现媒体地址，共享 Go HTTP 下载器负责下载、进度汇报、取消和文件校验。视频封面可以作为缩略图处理，但不能将单张封面当成图文内容。
- 小红书适配器负责已登录用户会话下的博主主页/笔记列表分页、单条笔记详情、图片/视频类型区分以及图文内容字段。由于网页协议未公开，需以脱敏固定响应样本建立解析回归测试，并实施请求节流与有限重试。

### B 站复用

B 站视频仍由 yt-dlp 下载；B 站空间扫描、动态解析和图文图片下载继续由专用适配器提供。共用核心不依赖 B 站 API 或 yt-dlp 的 JSON 字段。

## 技术设计

### 平台边界

建立平台注册表，目前注册 `bilibili` 和 `xiaohongshu`。每个平台适配器实现以下能力：

1. 识别并规范化创作者主页 URL。
2. 登录状态、扫码登录流程和登出。
3. 按分页扫描创作者的内容，输出平台无关的归档条目。
4. 提供平台策略，例如扫描/下载节流、分页限制和平台错误分类。

适配器负责平台协议、Cookie、响应解析及内容 URL。共享应用层负责扫描调度、首次基线、去重、历史拉取作业、任务队列、并发、重试、状态持久化及本地目录边界。媒体下载通过共享接口路由到 yt-dlp 视频下载器或 HTTP 图片下载器。

公共扫描流程只根据平台注册表获取适配器，不增加 `if platform == ...` 分支。添加平台时，新增适配器和登录提供器，并声明能力。

### 登录与凭据

- B 站与小红书都必须先登录才能扫描、拉取历史或下载受保护媒体。
- 前端提供统一登录状态和操作布局；每个平台适配器各自实现适用的交互，B 站和小红书均使用平台扫码。
- 登录 Cookie 及会话分别存放，不复用全局 `cookiesFile`，文件权限限制为当前系统用户；状态 API 不回传 Cookie 内容。
- 扫描与下载开始前检查会话。会话失效时任务失败并给出重新登录提示，不匿名重试。
- 日志禁止写入 Cookie、签名参数、二维码会话密钥和完整敏感请求地址。

### 统一内容模型

统一内容类型为 `video` 和 `image_post`，移除 B 站专属 `dynamic` 语义。归档条目至少包含：平台、创作者 ID、平台内容 ID、类型、标题、正文、来源 URL、封面、视频时长、媒体 URL 列表及发布时间。媒体 URL 只在运行时用于下载，不持久化认证 Cookie 或签名头。

创作者按统一的“监听视频/监听图文”能力配置。任务以平台 + 创作者 + 内容 ID + 类型唯一去重。图文完成后保留正文、图片文件和元数据 JSON，并支持压缩包下载；视频任务保留已选画质、封面和本地视频文件。

存储结构可直接调整为新模型，不保留面向旧字段的长期兼容分支。若实现时需要处理现有 JSON 状态，应做一次有明确版本号的正向迁移，避免未告知地清空现有订阅和任务。

### 首扫与历史拉取

- 首次成功扫描默认建立基线，不将已有内容加入下载队列。
- 用户选择“归档最近内容”时，首批各内容类型最多加入最近 10 条。
- 后续周期扫描发现的新内容进入共享队列。
- 两个平台都提供手动历史拉取，通过适配器分页；共享历史作业控制暂停、继续、取消和已存在内容跳过。
- 每个平台使用独立节流参数，避免 B 站冷却策略与小红书请求策略相互影响。

### 前端调整

- 添加订阅仅接受 B 站空间地址/UID 与小红书博主主页地址；自动识别平台。
- 内容类型选项根据平台能力展示“视频”和“图文”。
- 订阅卡片、任务列表、内容库和预览统一显示平台名、内容类型和来源链接。
- 设置页按平台展示登录状态、扫码、重新登录与登出。
- 删除 YouTube 添加入口、品牌文案、数据类型和条件判断；产品名可维持 BiliFetch，除非产品设计另行决定改名。

### 错误与安全

- 区分登录过期、二维码过期、平台限流/验证码、解析结构变化、媒体下载失败和本地文件错误。
- 认证错误要求用户重新登录；限流采用平台独立退避；解析错误保留安全截断后的诊断信息。
- 图像下载器只允许 B 站/小红书媒体域名及明确的 HTTPS 重定向目标，防止内容 URL 被利用访问内网。
- 图片逐张下载，任何一张失败都使归档任务失败并可重试，避免产生不完整的“成功”存档。
- 扫描分页设时间/页数上限，任务和并发继续沿用应用级限制。

## 验证方案

- Go 单元测试：URL 规范化、平台注册、统一条目映射、基线/最近 10 条、去重、平台 Cookie 隔离、首扫登录强制、历史分页、节流互不影响。
- 解析测试：用脱敏 B 站与小红书响应样本验证博主列表、视频条目、图文正文与多图 URL 提取。
- 媒体任务测试：用本地测试 HTTP 服务覆盖图片下载、视频 yt-dlp 进程参数、取消、重试、进度、部分图片失败和安全域名限制。
- 登录测试：模拟两平台扫码状态、过期与登出；保证一个平台的登录/退出不修改另一平台的会话。
- 前端验证：TypeScript 检查和构建；手动检查添加 B 站/小红书订阅、扫码状态、视频/图文筛选、内容预览与历史拉取。
- 真实账号烟雾验证应分别确认：登录成功、主页笔记分页、至少一条图文的所有图片、至少一条视频、重启后会话复用。任何真实平台限制需记录为限制，不以模拟响应代替端到端结论。

## 主要风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 小红书网页 API/签名变化 | 登录、扫描或媒体 URL 解析可能中断 | 将协议隔离在 XHS 适配器；保存脱敏样本；错误可见；限制请求频率 |
| 小红书验证码或 IP 风控 | 自动扫描暂停 | 识别风控状态并退避，不循环重试；提示用户在登录流程/平台客户端完成验证 |
| yt-dlp 小红书提取器变化 | 个别视频任务无法下载 | 固定 yt-dlp 可配置版本；解析失败提供重试；XHS 视频下载器边界可替换 |
| Cookie 过期或账号切换 | 任务失败或使用错账号 | 登录状态按平台存储，检查账号态，失效时要求重新扫码 |
| 媒体 URL 短期签名过期 | 历史队列媒体下载失败 | 任务开始下载前重新获取条目详情和媒体 URL，不长期保存签名链接 |
